Market Risk Classification for Bitcoin

Machine Learning · Time Series · MLOps

GitHub ↗

Currently under active development and continuous expansion.

Credit Card Fraud Detection Pipeline

XGBoost · Imbalanced Learning · Optuna

GitHub ↗
  • Developed a machine learning pipeline for credit card fraud detection using XGBoost on highly imbalanced transaction data.
  • Implemented SMOTE and scale_pos_weight to improve minority class detection.
  • Performed hyperparameter optimization with Optuna and evaluated models using Precision, Recall, F1-score, ROC-AUC, and PR Curve.
  • Achieved approximately 90% Precision and 85% Recall through model tuning and threshold optimization.
  • Addressed extreme class imbalance with 284,315 legitimate and 492 fraudulent transactions.
